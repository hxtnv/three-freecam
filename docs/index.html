three-freecam

A debug camera for Three.js. Editor-style scene-view controls, the way Unity, Unreal and Godot do it. Right-drag this page and fly.

npm i three-freecam
Read the guide npm Source

Live options

pos 0, 0, 0
speed 16 u/s
right-drag look · wasd fly · q/e down/up · shift boost
middle-drag pan · wheel dolly · wheel while looking speed
alt + left-drag orbit · f frame the pivot
This demo needs a mouse and a keyboard. three-freecam is a desktop debug camera and has no touch support. Read the guide instead.
